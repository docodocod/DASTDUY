## if문
>if (조건식) {<br>
>   // 조건이 참일 때 실행되는 코드<br>
}
- 조건식은 boolean 타입이어야 하며, true 또는 false를 반환합니다.
- 중괄호 {} 안의 코드는 조건식이 true일 때만 실행됩니다.

## if문의 예시
>int age = 18;<br>
if (age >= 18) <br>{<br>
System.out.println("성인입니다.");<br>
}

출력값
>성인입니다.

## if-else 문
![img_1.png](img_1.png)
>if (조건식) <br>{<br>
// 조건이 참일 때<br>
} else {<br>

}

## if-else 문의 예시
>int score = 95;<br>
if (score >= 90) <br>{<br>
System.out.println("A학점 입니다.");<br>
} else {<br>
System.out.println("A학점이 아닙니다.");<br>
}

## if - else if - else 문
#### 여러 조건을 순차적으로 검사할 때 사용합니다.
![img_2.png](img_2.png)
>if (조건1) <br>{<br>
// 조건1이 참일 때<br>
} else if (조건2) {<br>
// 조건2가 참일 때<br>
} else {<br>
// 모든 조건이 거짓일 때<br>
}

## if-else if- else문의 예시
> int score = 85;<br>
if (score >= 90) <br>{<br>
System.out.println("A학점");<br>
} else if (score >= 80) {<br>
System.out.println("B학점");<br>
} else if (score >= 70) {<br>
System.out.println("C학점");<br>
} else {<br>
System.out.println("F학점");<br>
}

## 논리 연산자
- 논리 연산자(logical operators)는 불리언(boolean) 값을 다루는 연산자로, 조건문에서 주로 사용됩니다. 각각의 논리 연산자는 참(true) 또는 거짓(false)을 판단하고 조합하는 데 사용됩니다. 자바의 주요 논리 연산자는 다음과 같습니다:
1. && (논리 AND)<br>
   두 조건이 모두 true일 때만 true를 반환합니다.<br>
하나라도 false면 결과는 false입니다.<br>
> boolean result = (5 > 3) && (10 > 7);  // true && true → true

2. || (논리 OR)<br>
   두 조건 중 하나라도 true면 true를 반환합니다.<br>
둘 다 false여야만 결과가 false입니다.<br>
> boolean result = (5 < 3) || (10 > 7);  // false || true → true

3. ! (논리 NOT)<br>
   조건의 참/거짓을 반대로 바꿉니다.<br>
true → false, false → true<br>
> boolean result = !(5 > 3);  // !(true) → false

## switch 문
- switch 괄호 안의 값(변수) 을 case 들과 순차적으로 비교함.<br>
- 일치하는 case를 만나면, 해당 블록 실행 후 break로 빠져나감.<br>
- break가 없으면 아래 case 들도 계속 실행됨.<br>
- default는 모든 case에 해당하지 않을 경우 실행 (선택사항).<br>
